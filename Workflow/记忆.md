## 二、这是什么项目

- 路径：`C:\你的路径\AIAgent4MC`
- 参加**南大「AI Agent for Minecraft」开发大赛 · Harness 赛道**；
- 赛道要求：**统一模型 + AIA 统一代理 API + NMO 的 Bot 接口**，自己设计 Harness（规划/记忆/工具调用/状态维护/行为策略）；
- 比赛规则（详见 `Doc/参赛要求.md`）：
  - 初赛 11 月 22 日 10:00–18:00，8 小时；**每人一座相同的虚空岛**（主世界 + 下界，末地共用）；
  - 成绩 = 游戏表现分 60（advancement 得分，按全场最高归一化）+ 工程评审 40；
  - 单项 advancement 分**只由难度决定**（5/15/30/60/100，v2 草案取消深度加成）；官方计分表 99 项计分（3385 分）；
  - 只算**原版非配方** advancement；
  - token 额度：输入 800 万 / 输出 150 万；单队并发 ≤ 4；
  - 禁止人工代打、禁止外部模型服务绕额度。

## 三、现在的架构（v2，2026-11-13 重构）

```
main.py（入口）
  └─ agent.py（主循环：观察→保命→决策→执行→记账）
       ├─ planner.py（问模型要「下一个技能」，上下文约 1k）
       ├─ skills.py（技能：chop_tree/collect/craft/smelt/eat/...）
       ├─ world_state.py（状态+记忆，落盘 state/world_state.json）
       ├─ advancements.py（计分）
       ├─ mc_api.py（比赛服接口）或 my_server/（自有服）
       └─ trajectory.py（logs/run-*.jsonl + 任务记录.md）
```

**核心思想**：模型低频规划（≈1k tokens/次），代码高频执行（一次技能 = 几十个 API 动作）。

## 四、关键事实（务必记住）

1. **密钥在 `Codes/.env`**，不在 `config.py`。`.env` 已 gitignore。
2. 旧的 API key 曾进过 git 历史与 README（旧提交 `519e49c`），**必须轮换**；旧 `.git` 已删除并重建，
   新仓库 `AIAgent4MC` 是干净历史，旧哈希只作记录、本地已找不回。
3. 旧版三个模块已删：`deepseek_client.py`、`tools.py`、`brain_memory.py/.json`；
   旧 `.git` 删除后无法用 `git show` 找回，需要的话从备份/旧仓库找。
4. 入口命令：`run / learn / learn --manual / test-api / test-mc / status / strategy / report / ping / mock / reset`；
   守护：`supervisor.py`。
5. 运行数据：`Codes/state/`、`Codes/logs/`（都已 gitignore）。
6. 自有服务器：`Codes/my_server/`，接入代码在 `main.build_backend()` 里**注释掉**，按需打开。
7. 测试：`python -m unittest discover -s tests -v`（82 项，离线）。
8. 官方计分表：`Doc/RULES.md`（草案 v2）里；`python Codes/build_scores_table.py` 会生成
   `Codes/data/advancement_scores.json`（99 项计分 / 3385 分）。规则更新后重跑这个脚本即可，不用改代码。
9. **虚空岛**：`skills.survey` 做岛屿勘察，`explore` 限 24 格；提示词里写明「不要走远」。掉虚空会死。
10. **策略**：`Codes/data/strategy.md`（自由文本，LLM 自己拆解）优先；`strategy.json` 兼容；
    默认 JSON 为空、不预设阶段；改完下一轮生效（按 mtime 热更新）；
    `python main.py strategy` 查看；策略是**软约束**，不是硬流程。
11. **网络延迟**：`python main.py ping` 测 DNS/TCP/TLS（不花 token）；运行时**每次交互**都记录：
    每条 API 请求（`↔` 行）、每次 LLM 调用（`🤖` 行）、每次 `/status`；
    `report` / `任务记录.md` 汇总 avg/p95；`PRINT_LATENCY=false` 可关闭逐条打印；
    单次超过 `NET_LATENCY_WARN_MS`（默认 3000）会打告警日志。
12. **学习层（v3）**：`python main.py learn --minutes N`；实验/提问/写 memory，
    memory 在 `Codes/state/knowledge.json/md`，决策层 `Planner` 每次读摘要；
    学习层不冲分、不读 strategy，只开安全技能；比赛当天不要跑（会等输入）。
13. **接口**：`mc_api.py` 覆盖规范 v1.3 全部端点，动作方法支持 `stop_on`；
    `my_server` 适配器同步。配方选择已修：本地桥遍历所有配方按库存选，`missing_total` 给缺口。

## 五、约定 / 偏好

- 用中文；命令给全，能复制粘贴；
- **不要替用户主动调用外部接口**（DeepSeek / 比赛服），需要验证时让用户自己跑 `test-api` / `test-mc`；
- 改完代码必须同步更新文档（`Workflow/README.md`、`使用步骤.md`、`详细教程.md`、`harness架构.md`、`记忆.md`、`项目问题清单.md`）；
- 新增功能要能在 `python main.py mock` 和单测里跑通，再上真服；
- 提交前确认 `.env` / `state/` / `logs/` 没被加进 git。
