# 使用步骤（一页版 · 2026-11-16）

> 照着从上往下做就行。详细解释看 [`README.md`](../README.md)、[`学习层与决策层.md`](学习层与决策层.md) 和 [`详细教程.md`](详细教程.md)。

---

## 第 0 步：整体流程

```
装 Python → 装依赖 → 复制 .env 并填 → 离线自检 → 测大脑 → 测 Bot
→ （可选）学习层学规则 → 写 strategy.md → reset → 开跑
```

| 步骤 | 命令 | 作用 | 联网 | 花 token |
|---|---|---|---|---|
| 自检 | `python main.py mock` | 不联网验证代码 | 否 | 否 |
| 测大脑 | `python main.py test-api` | 验证代理/模型 | 是 | 一点点 |
| 测 Bot | `python main.py test-mc` | 登录 + 等上线 + 打印状态 | 是 | 否 |
| 学习 | `python main.py learn --minutes 20` | 学规则/问答/写 memory（会等你输入） | 是 | 少量 |
| 手动测动作 | `python main.py learn --manual` | `do`/`call` 逐条测试，不花 token | 是 | 否 |
| 写策略 | `copy data\strategy.example.md data\strategy.md` | 自由文本，LLM 自己拆解 | 否 | 否 |
| 清状态 | `python main.py reset` | 新开一局 | 否 | 否 |
| 看策略 | `python main.py strategy` | strategy.md / JSON 当前内容 | 否 | 否 |
| 看统计 | `python main.py report` | 最近一次运行的成功率/进度/token | 否 | 否 |
| 测延迟 | `python main.py ping` | DNS/TCP/TLS 延迟 | 否 | 否 |
| 开跑 | `python main.py run` | 决策层（比赛模式） | 是 | 是 |

> 想在自己的局域网世界测试：见 [`局域网测试指南.md`](局域网测试指南.md)（需要 Node.js + `Codes/local_bot/`）。

## 第 1 步：装环境

```bat
cd /d C:\你的路径\AIAgent4MC\Codes
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

看到 `(venv)` 就对了。依赖只有 `requests`。

> 如果文件夹里已经有 `Codes\venv`（别人拷给你的），先删掉再重建。

---

## 第 2 步：填 `.env`（三样东西）

```bat
copy .env.example .env
```

用记事本打开 `Codes\.env`：

```ini
LLM_BASE_URL=https://api.deepseek.com/v1   # 比赛换成 AIA 代理地址
LLM_MODEL=deepseek-chat                     # 比赛换成代理给的模型名
LLM_API_KEY=sk-你的key
MC_USERNAME=你的皮肤站用户名
MC_PASSWORD=你的皮肤站密码
```

- `.env` 不会进 git；
- **比赛必须用 AIA 统一代理**（规则硬要求），拿到地址后只改这三行。

## 第 3 步：离线自检

```bat
python main.py mock --ticks 12
```

看到 `自检完成 ✅` 就说明代码没问题。这一步不花钱、不连服务器。

## 第 4 步：测大脑

```bat
python main.py test-api
```

```
✅ 模型回复：连接成功
🪙 输入 13 / 8000000 tokens，输出 4 / 1500000，调用 1 次
```

- `401` key 错；`402` 没余额；`404` 地址少了 `/v1`。

---

## 第 5 步：测 Bot

```bat
python main.py test-mc
```

看到「Bot 已在比赛服」即通。报错对照：

| 报错 | 解决 |
|---|---|
| `invalid_credentials` | 核对 `.env` 的账号密码 |
| `no_profile` | 去 skin.nmo.net.cn 选定角色 |
| 长时间 `ready=false` | 多等 20 秒，程序会自动重试 |

---

## 第 6 步：开跑

### 比赛前

```bat
python main.py reset
```

### 正式跑（推荐守护模式）

```bat
python supervisor.py --until 18:00
```

或者直接：

```bat
python main.py run --until 18:00
```

### 联调（只跑 30 分钟）

```bat
python main.py run --minutes 30
```

## 第 8 步：怎么停 / 怎么恢复 / 怎么重开

| 想干什么 | 怎么做 |
|---|---|
| 正常停 | `Ctrl + C`（会保存状态、写总结） |
| 到点自动停 | 到 `COMPETITION_END` 前 1 分钟自动收尾 |
| 崩了恢复 | 再跑 `python main.py run`（读状态接着跑） |
| 新开一局 | `python main.py reset` |
| 看 Bot 现在怎样 | `python main.py status` |

## 常见问题

**1. 启动就退出**
→ `.env` 没填对。先 `python main.py test-api`。

**2. 中文乱码**
→ 程序已强制 UTF-8；若仍乱码，先 `chcp 65001`。

**3. 进度一直是 0**
→ `/advancements` 还没下发，等第一次刷新（默认 90 秒）。

**4. 想清空记忆重来**
→ `python main.py reset`。

**5. 换电脑**
→ 只拷代码，**不要拷 `venv`**；重新装依赖 + 填 `.env`。
