# 本次改动（2026-11-16）：学习层 + 自由策略 + 接口/配方修复

> 目标：从「一上来就冲分」改成「先学规则，再按用户写的策略打」。
> 兼容旧命令：`run` 仍是决策层；新增 `learn` 学习层。

---

## 1. 学习层（新增）

- `Codes/learn.py`：学习主循环；
- `Codes/knowledge.py`：memory 读写/导出；
- `python main.py learn`：
  - LLM 做实验 / 问用户 / 记录规则；
  - memory 存 `Codes/state/knowledge.json` + `knowledge.md`；
  - 默认只开安全技能（survey/scan/砍树/采集/合成/熔炼/吃/装备/放置/探索）；
  - 不读 strategy、不冲 advancement。

### 学习层动作

| 动作 | 说明 |
|---|---|
| `ask_user` | 有疑问问终端前的你，回答写 memory |
| `experiment` | 调技能做实验，记录结果/背包变化 |
| `record_rule` | 写规则 |
| `record_skill` | 写技能经验 |
| `scan` / `survey` / `done` | 快捷动作 / 结束 |

### 命令

```bat
python main.py learn --minutes 20
python main.py learn --ticks 30
python main.py learn --reset-knowledge
python main.py learn --manual          :: 手动动作测试（do/call，不花 token）
```

### 学习流程（本轮调整）

- **先问后做**：`must_ask=true` 时第一轮强制 `ask_user`，回答后才允许实验；
- **按事件组织**：最近 8 条 `events`（chat/hurt/death/进度）进入提示词，模型先解释情境再行动；
- **情境记忆**：每次运行开一个 `episode`，问答/实验/规则都追加到同一段；`memory.summary()` 带最近情境，
  下一轮可以接着上一轮做，不再是一堆孤立实验；
- `knowledge.md` 新增“学习情境”章节。

## 2. 决策层读 memory

- `Planner` 每次决策把 `knowledge.summary()` 放进提示词（规则/技能/用户问答）；
- 学习层学到的结论会直接影响比赛决策；
- 决策层仍不读学习层的“实验过程”，只读摘要，省 token。

---

## 3. 策略层：`strategy.md` 优先

- 新增 `Codes/data/strategy.example.md`（模板，复制成 `strategy.md`）；
- `Strategy` 同时支持：
  - `strategy.md`：自由文本，LLM 自己阅读/拆解（**推荐**）；
  - `strategy.json`：兼容 phases/targets/avoid；
- 默认 `strategy.json` 改为**空策略**（mode=custom、无 phases/targets/avoid），不再预设打法；
- 不写策略时，Agent 只保证生存/基础盘，不擅自冲分；
- `run --strategy data\strategy.md` 可直接指定；
- `python main.py strategy` 优先显示 md。

## 7. 聊天模式（新增）

`python main.py chat`：终端/游戏内聊天 → LLM → **≤25 字/条** 回复，并发到游戏聊天。
system prompt 很短、`max_tokens=48`、1.2 秒冷却；不执行动作，只说话。

---

## 8. 强制控制热键

`python main.py run` 运行中：

| 键 | 行为 |
|---|---|
| `q` | 暂停/继续；暂停时调用 `/stop` 打断当前走位/挖掘 |
| `e` | 强制下线：`/stop` → `disconnect` → `logout`，退出主循环 |

Windows 控制台生效；`learn`/`chat`/`learn --manual` 要用终端输入，不启用热键（用 Ctrl+C/exit）。

## 9. 兼容性

| 旧用法 | 现在 |
|---|---|
| `python main.py run` | 仍可用（决策层） |
| `--strategy data\strategy.json` | 仍可用（JSON 兼容） |
| 默认 JSON 阶段 | 改为空；要旧行为请显式写 phases |
| `python main.py mock` | 仍可用 |

> 学习层和决策层共享 `world_state.json`；建议赛前先 `learn`，再 `reset` + `run`，
> 避免学习时的走位/背包影响正式局（memory 不受 reset 影响）。
