# 本次改动说明（2026-11-13）

> 一句话：**从「一个动作问一次大模型的 Demo」重构成「advancement 驱动、8 小时无人值守的 Harness」**，
> 同时把合规、token 预算、状态记忆、可复盘这几件事补齐。

---

## 一、为什么要重写

详细诊断见 [`项目问题分析-2026-11-13.md`](项目问题分析-2026-11-13.md)，四个根因：

1. **目标函数错位**：比赛 60 分是 advancement，而旧版从不调用 `/advancements`，目标写死成「砍树合成工作台」。
2. **跑不了 8 小时**：任务之间 `input()` 等人打字；单任务 50 轮上限；没有比赛时钟。
3. **token 撑不住**：每个动作一次全量对话、历史只增不减，按模型估算约 140 轮就把 800 万输入额度烧完。
4. **合规与复现**：模型直连 DeepSeek（规则要求 AIA 统一代理）；`test-api`/`test-mc` 两个入口 NameError；`requirements.txt` 被删。

## 三、行为上的变化（重要）

| 以前 | 现在 |
|---|---|
| `python main.py` 直接跑（交互式） | `python main.py` 打印帮助；跑比赛用 `python main.py run` |
| 每做完一个任务问你下一个 | **不问**，自己按 advancement 目标连续跑 8 小时 |
| `python main.py test-api` 崩溃 | 正常调用模型并打印 token 用量 |
| 密钥写在 `config.py` | 在 `Codes/.env`，代码里没有 |
| 目标写死在 `config.GOAL` | 由 advancement 计分驱动；`GOAL` 只在调试时用 |
| 只记 `任务记录.md` 四行 | 每次运行写 `logs/run-*.jsonl`（每步可回放）+ 任务记录总结 |
| 掉线要人重启 | 自动重连；`supervisor.py` 崩溃自动拉起，状态不丢 |

---

## 四、你只需要做三件事

1. **换模型地址**：拿到 AIA 代理后，改 `Codes/.env` 里 `LLM_BASE_URL / LLM_MODEL / LLM_API_KEY` 三行；
2. **轮换密钥**（必做）：旧 key 已经进了 git 历史（`git show 519e49c:Codes/config.py`），
   去 DeepSeek 后台作废重发；皮肤站密码也建议改。新的写进 `.env`，别再写进 `config.py`；
3. **赛前自检**：`python main.py mock` → `python main.py test-api` → `python main.py test-mc` → `python main.py run --minutes 30`。

## 七、规则草案 v2 适配（同日傍晚）

项目里新增 `Doc/RULES.md`（初赛规则草案 v2，原在根目录），主要变化和对应改动：

| 规则 v2 | 改动 |
|---|---|
| 每人一座**虚空岛**（主世界+下界），四周是虚空 | 新增 `survey` 技能勘察岛上结构；`explore` 上限压到 **24 格**防掉虚空；提示词写明「不要走远」 |

| 官方计分表 99 项计分（3385 分），很多「岛上有没有」条件 | `Codes/data/advancement_scores.json` **由 `RULES.md` 自动生成**，含 `scored`/`condition` |

| 只允许在自己的岛和共用末地活动 | 不做跨岛策略；`flee`/`explore` 都限制在小范围 |
